# 焼肉屋はじめました

一人称で焼肉屋の店員として働く、リアル寄りの焼肉屋シミュレーター（Godot 4.5 / Windows）。

## ダウンロード

[最新版（Windows・zip）](../../releases/latest/download/yakiniku-hajimemashita-windows.zip) を展開して `yakiniku-hajimemashita.exe` を起動します。
署名なしのため、Windowsの警告が出たら「詳細情報」→「実行」を選んでください。

## 遊び方

あなたは焼肉屋の店長（資金 ¥300,000 から）。

1. 毎朝、向かいのアパートの自宅から歩いてお店へ。入口のタイムカードをEで押して出社
2. 入口横のシフト表（E）でアルバイトを雇える（焼き担当・ホール担当・片づけ担当）
3. 入口の札をEでひっくり返して開店
4. 自分でも冷蔵庫の肉をカウンターの七輪で焼いて出したり、テーブルの注文を聞いて運んだりできる
5. 星をもらうと店の格が上がり、タッチパネル・食洗機・自家カット・高級部位・営業延長が買える（Bのカタログ）
6. お客さんには常連・団体・クレーマー・食通がいる

| 操作 | キー |
| --- | --- |
| 移動 / 走る | WASD・↑↓ / Shift |
| 向きを変える | マウス・← → |
| つかむ・置く | 左クリック |
| ひっくり返す | 右クリック |
| 空気口（火力）・部位の切り替え | ホイール |
| 使う（長押しで網を洗う） | E |
| お店づくり（開店前・閉店後） | B（中で T: カタログ、R: 回す、X: 売る） |
| メニュー・画質 | Esc |

- 七輪は網の中央ほど熱く、炭が減ると火が弱まる。網を外して炭箱の炭を入れると戻る
- 脂の多い肉は炎が上がって焦げやすい
- 網は焼くほど汚れて焦げつく。外してシンクでE長押しで洗うか、網置き場のきれいな網と交換
- 食べ終わったお客さんは入口手前のレジに並ぶ。レジを見て E でお会計（ホール担当のアルバイトがいればレジも打ってくれる）。待たせすぎると評価が下がる
- お客さんとアルバイトは Higgsfield で作ったリアルな3Dの人（`assets/people/`）、肉は写真から作った見た目（`assets/meat/`）
- 歩きはモデルに入っている動き。立つ・座る・食べる・手を挙げる・お盆を持つは `scripts/body_pose.gd` が骨の向きで姿勢を作る
- 閉店後の結果画面と次の日の朝に自動でセーブ（`user://save.json`）。起動画面の「続きから」で再開
- お店づくりモードでは、テーブルや冷蔵庫・シンク・ドリンク台を持ち上げて動かせる。カタログでテーブル席・観葉植物・壁紙・床・隣の区画を買える。お客さんは配置に合わせて道を探して歩く

## 開発

- `scripts/` … ゲームの中身（`grill.gd` 七輪と火、`meat.gd` 焼け具合、`customer.gd` お客さん など）
- `shaders/meat.gdshader` … 肉の焼き色
- 開発用：`godot --path . -- --test` で一連の操作を自動確認、`-- --shot=<dir>` でスクリーンショット
- `main` / 開発ブランチへの push で GitHub Actions が Windows 版を書き出して Releases に公開
